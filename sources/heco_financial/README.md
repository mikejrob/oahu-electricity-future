# Hawaiian Electric financial statements

`HEI_Annual_Report_2024.pdf` — Hawaiian Electric Industries, Inc., Annual
Report to Shareholders for 2024, as filed with the SEC
(sec.gov/Archives/edgar/data/354707/000110465925029354/tm2422591d7_ars.pdf).

Used in Box 4.2 to put the Integrated Grid Plan's transmission capital in
perspective. The figures cited come from the **utility-only** balance
sheet, "Hawaiian Electric Company, Inc. and Subsidiaries" (p. 98) — not
the HEI consolidated statements (p. 92), which also carry non-utility
assets:

|---|---:|

| Plant and equipment | 8,421,501 |
| Right-of-use assets — finance lease | 447,101 |

| Less accumulated depreciation | (3,326,624) |
| **Utility property, plant and equipment, net** | **5,959,706** |

Gross utility plant is therefore about $9.29 billion and net book value
about $5.96 billion, covering generation, transmission and distribution
across all three utilities (Oʻahu, Hawaiʻi Island, Maui County).

For comparison, the IGP base scenario's Oʻahu transmission capital is
$9.77 billion nominal over 2029-2050 (IGP Table 8-13; Table 9-2), which
deflates to roughly $6.0 billion in 2024 dollars at 2-3 percent inflation.
